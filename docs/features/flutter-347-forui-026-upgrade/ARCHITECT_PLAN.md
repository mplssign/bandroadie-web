Feature: `feature/flutter-347-forui-026-upgrade`

Title: Unblock Flutter 3.47 upgrade — bump forui 0.25.0 -> 0.26.0, revert CI pin

Date: 2026-08-25

## Decision Record

### 1) forui version bump

- Updated dependency constraint from `forui: ^0.25.0` to `forui: ^0.26.0` in `pubspec.yaml`.
- Ran real `flutter pub get` on Flutter 3.47.1 and verified lock resolution:
  - `forui` resolved to `0.26.0`
  - `forui_lucide` resolved to `0.26.1`
  - `forui_assets` removed from dependency graph

### 2) Flutter CI pin revert/change

- Previous temporary emergency pin in CI was `flutter-version: "3.44.6"`.
- Looked up current stable patch from Flutter archive at execution time:
  - https://docs.flutter.dev/install/archive
  - current stable observed: `3.47.1`
- Updated `.github/workflows/flutter_ci.yml` to exact pin:
  - `flutter-version: "3.47.1"`
- Recommendation (explicit): keep exact patch pinning for CI safety.

Tradeoff documented:

- Exact pin (chosen): deterministic CI, no silent major/minor/patch drift, manual upgrades required.
- Floating `channel: stable` (not chosen): lower maintenance, but can silently adopt breaking changes and cause surprise CI failures.
